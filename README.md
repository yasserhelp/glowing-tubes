# 🌈 Glowing Tubes Cursor

An interactive glowing tubes effect built using **HTML**, **CSS**, and **JavaScript**.  
Move your cursor and watch the light trails dance smoothly across the screen! ⚡  

---

## 🧠 Technologies Used
- **HTML5** — structure and layout  
- **CSS3** — design, glow & animation  
- **JavaScript (Three.js)** — dynamic 3D glowing effect  

---

## 🚀 Live Demo
🔗 [View Project on GitHub Pages](https://yasserhelp.github.io/glowing-tubes/)

---

## 🧩 Features
- Real-time animated glowing trails  
- Interactive cursor effects  
- Lightweight and responsive  
- Uses Three.js for dynamic visuals
